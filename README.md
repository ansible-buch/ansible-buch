# Dear visitor,

here you can find downloadable supplements for my book
"[Ansible: The Practical Guide for Administrators and DevOps Teams](https://www.sap-press.com/ansible_6068/)",
published by Rheinwerk Publishing.
The first edition has been available since July 2025.

I have compiled this material with great care and will also incorporate future
developments. The material will therefore also contain corrections and updates.

If you notice any errors in the book or if an example simply refuses to work,
create an issue here on GitHub, or
just send me an email: [ansible-buch@am42.de](mailto:ansible-buch@am42.de).

> :warning: Attention:
>
>
> For some of the repositories, I’ve represented the different editions
> using branches. The default branch is currently `3rd-edition`.
> This may seem confusing, but it's correct: the first English edition is
> a translation of the third German edition, so the code examples are
> completely identical.
> Only the listings are stored in two separate repositories
> (`listings-de` and `listings-en`), since the chapter names appear there.
>
> If applicable, there might be a branch called `devel` that gives a
> preview of future developments;
> however, it may also contain things that don't match the version of the book
> you're currently using.
